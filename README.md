# Micron Conversion Calculator

A single-page calculator for converting microns, millimeters and inches, built for sizing screen openings in the field. Works on phones.

- Multiply/divide reference chart
- Live converter
- Inches opening to microns, using both the chart method (divide by 0.00003937) and the exact method (multiply by 25,400)

Live: https://randallu88.github.io/micron-conversion-calculator/
